The game

Three rules, one impossible task

This is the Mermin–GHZ game. No plan agreed in advance can win every round, because the right answer depends on every card and each player sees only one.

01 · THE DEAL

Everyone gets a card

Each player gets a 0 or a 1. The referee always deals an even number of 1-cards.

02 · NO TALKING

Answer blind

Each player answers 0 or 1, seeing only their own card.

03 · THE WIN

Add up the answers

The team wins or loses together. Whether the total must be even or odd depends on how many 1-cards were dealt.

Example with 3 players. There are only four possible deals:
Cards dealt1-cardsTo win, the answers must add up to
0 · 0 · 0nonean even number
1 · 1 · 0twoan odd number
1 · 0 · 1twoan odd number
0 · 1 · 1twoan odd number

Say the cards are 1, 1, 0. If the players answer 1, 0, 0, the total is 1, which is odd, so the team wins. If they answer 1, 1, 0, the total is 2, which is even, so the team loses.

The catch. A player holding a 0 can't tell whether the deal was 0 · 0 · 0 (even needed) or one with two 1-cards (odd needed), and nobody can ask. That is why the best classical plan wins only 3 deals out of 4. For bigger teams it's the same idea: with 0, 4, 8… 1-cards the total must be even, and with 2, 6, 10… it must be odd.

How the quantum team wins. The players share entangled qubits, one each. A player holding a 1 gives their qubit a quarter twist, then everyone measures. Each answer alone looks random, but entanglement makes the total come out right every time. The app plays both teams side by side, and a sabotage switch shows that one wrong gate is enough to break the quantum team.
The accuracy test

How far can the simulator compress before the quantum team loses?

Quantum Rings fits big circuits on a laptop by compressing, controlled by a dial. We send the players' qubits through a 20-qubit scrambling circuit and exactly back, then play. A perfect simulation keeps the quantum team at 100%. Too much compression and it starts losing, at the lowest setting even below the best classical team.

Run it

Run it on your own laptop

You can also run the app on your own machine, which is how we ran the 200-qubit games. You need Python 3.11+ and a free Quantum Rings SDK key.

git clone https://github.com/Cooldode/quantumxp
cd quantumxp
python3.11 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export QR_TOKEN="your-sdk-key"
export QR_ACCOUNT="your-account-email"
streamlit run app.py
